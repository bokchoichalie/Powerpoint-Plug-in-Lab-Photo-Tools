# Lab Photo Tools 0.1.16 — PowerPoint 사진 도구

Windows 데스크톱 PowerPoint용 COM 추가 기능입니다. 사진은 로컬 Python 엔진에서 처리합니다.

## 치수측정 (0.1.16)

PowerPoint 상단 **Lab Photo Tools** 탭 안의 자 모양 **치수측정** 버튼을 사용합니다. 사진 한 장을 선택하고 버튼을 누르면 사진 위에서 직접 측정하는 창이 열립니다. 사진 한 장과 번호 라벨이 묶인 그룹이나 그룹 내부 사진도 선택할 수 있습니다.

1. **수동 스케일**에서 선, 평행선 또는 3점원을 선택합니다. 선은 스케일바 양 끝, 평행선은 기준선 2점과 반대쪽 선의 위치, 3점원은 원 둘레 3점을 클릭합니다.
2. 알고 있는 실제 길이와 단위(nm, µm, mm, cm)를 입력하고 **스케일 적용**을 누릅니다. 평행선은 두 선의 간격, 3점원은 지름을 입력합니다. 화면 확대와 관계없이 사진 좌표로 계산합니다.
3. 원하는 측정 도구를 선택하고 사진에서 점을 지정합니다. 도형별 조작 안내가 창 아래에 표시됩니다.
4. **측정 사진 복사**를 누르면 측정한 사진과 측정 도형·텍스트만 현재 슬라이드에 새 그룹으로 추가하고 선택합니다. 원래 사진은 유지하며 전체 슬라이드를 복제하지 않습니다. 원본 사진 그룹과 번호 라벨은 그대로 두고, 복사본에는 사진과 측정 표시만 넣습니다. 스케일만 저장하는 것도 가능합니다. **CSV 저장**으로 측정 목록을 저장할 수 있습니다.

Prusacope v19의 수동 측정 동작과 계산을 C#으로 옮겼습니다. 원본 참조: `bokchoichalie/Prusacope`, `prusacope_v19.py`, blob `dbaf9738046dff7ccef3a86767b8e48e68244918`의 MeasurePanel, MeasureToolsPanel, 도형 계산 및 측정 결과 처리. 현미경 카메라·스테이지 제어와 반자동 스케일/입자 검출은 이 기능의 범위에 포함하지 않습니다.

- 휠로 확대·축소, 가운데 버튼을 누른 채 이동합니다. 사진 측정 영역에서 WASD/방향키로 불러온 이미지의 1 px씩, Shift와 함께 누르면 10 px씩 이동합니다. 실제 포인터·십자선·확대창이 함께 움직이고 클릭 또는 Enter로 정확한 위치를 확정합니다. 글자·수치 입력란에서는 일반 입력 동작을 유지합니다.
- 다각형·곡선·꺾은선·평행선·점직선은 Enter 또는 우클릭으로 완료합니다. 자유곡선·자유선은 왼쪽 버튼을 누르고 그립니다.
- 선택 모드에서 도형을 끌어 이동하고 측정값 텍스트를 끌어 위치를 조정합니다. Ctrl+클릭으로 다중 선택, Ctrl+A 전체 선택, Delete 삭제, Ctrl+Z/Y 실행 취소·다시 실행을 지원합니다.
- 선 색·굵기·점선·채움과 글자 색·크기를 조절할 수 있습니다. 기존 항목은 선택한 뒤 **선택 도형에 서식 적용**을 누릅니다.
- 스케일과 측정 정보는 사진의 태그에 저장됩니다. 파일을 다시 열거나 사진을 비례 확대·축소해도 유지됩니다. 다시 치수측정을 열어 좌표와 값을 수정합니다. PowerPoint에서 직접 바꾼 측정 도형의 좌표/텍스트는 저장된 측정 계산에 반영되지 않습니다.
- 사진의 자르기·뒤집기·비율이 달라졌다면 **측정 초기화**로 측정 정보가 없는 사진 복사본을 현재 슬라이드에 만든 뒤 새로 보정합니다.
- 알아서 배열·자동 배열·간격 조절은 사진과 측정 그룹을 함께 움직입니다. 측정 사진에도 빠른 번호 라벨을 붙일 수 있습니다.
- 대화상자는 현재 모니터 작업 영역의 96% 크기로 열리며 테두리로 크기를 변경하지 않는 고정 창입니다. **사진은 항상 왼쪽에서 창의 전체 높이를 사용하며, 원래 비율을 유지해 가능한 최대 크기로 표시됩니다.** 전체 보기·확대/축소, 수동 스케일과 4:3 확대창, 측정 도구·서식·결과는 모두 오른쪽 패널에 모았습니다. 설정이 많거나 화면이 작으면 오른쪽 설정만 스크롤합니다. 사진은 아래로 내려가거나 설정과 함께 스크롤되지 않습니다. 사진 복사·닫기·CSV 저장 버튼은 오른쪽 아래에 표시합니다.
- 오른쪽의 측정 도구 21개와 점편집·곡률 자동·모서리 점 버튼은 **4열 × 6행**, 선택·삭제·실행 취소 등의 편집 버튼은 **4열 × 2행**으로 정렬합니다. 두 영역은 같은 버튼 크기를 사용하며 버튼 높이·여백을 줄였습니다. 긴 도구 이름과 아이콘이 잘리지 않도록 화면 배율에 맞춰 크기를 계산합니다.
- 미리보기는 PowerPoint에 보이는 사진의 회전·좌우/상하 반전을 그대로 반영합니다. 그룹에 적용된 회전과 반전도 포함합니다.

계산은 수동으로 지정한 스케일바와 점을 기준으로 합니다. 원·타원은 계산상 정확한 기하식으로 값을 구하고, PowerPoint에는 편집 가능한 자유형 도형으로 표시합니다.

## 0.1.16: 라벨 상자 서식과 곡선 편집

- 빠른 번호 매기기의 글자 설정 오른쪽에서 **테두리 색 · 테두리 (pt) · 바탕색**을 지정합니다. 색상표 또는 `#` 코드 입력을 사용하며 입력값은 Enter로 확정합니다. `기본`은 기존 형식별 모습(네모·원은 흰 바탕/검정 선, 괄호 라벨은 투명), `없음`은 해당 테두리 또는 바탕을 없앱니다. 굵기 0도 테두리 없음이며 0~20 pt를 지원합니다. 설정은 이후 추가하는 모든 형식의 라벨에 적용되고 자동 저장됩니다.
- **알파벳)** 형식은 `A)`~`K)`를 리본에 표시합니다. `L+`는 같은 형식의 다음 알파벳을 추가하며 Z 다음에는 AA, AB로 이어집니다. 기존 `(알파벳)`과 `숫자)`는 그대로 있습니다.
- **n점원**: 스케일을 적용한 뒤 테두리를 따라 최소 3개의 점을 순서대로 찍고 Enter 또는 우클릭으로 완료합니다. 모든 점을 통과하는 부드러운 닫힌 곡선이며 면적 A와 둘레 P를 표시합니다. 최대 512개 점을 지원합니다. 실제 원의 지름으로 가정하지 않습니다.
- **점편집**: 도형의 선이나 측정값, 또는 측정 결과 목록에서 하나를 선택하고 점편집을 누릅니다. 청록 사각 점을 드래그하면 위치가 바뀝니다. n점원의 주황 원형 핸들을 드래그하면 각 점에서 곡선의 방향과 휘어짐을 조절합니다. 점을 선택한 뒤 `곡률 자동`으로 자동 곡률을 복원하거나 `모서리 점`으로 뾰족하게 만들 수 있습니다. 기존 선·원·타원 등의 기준점도 이동할 수 있습니다.
- 편집할 때 측정값이 다시 계산됩니다. Enter 또는 그리기 완료로 편집을 끝내고, 이동 중 Esc는 해당 이동을 취소합니다. Ctrl+Z/Y로 되돌리기·다시 실행을 지원하며 점·곡률은 측정 사진 복사 시 저장되어 다시 열어도 유지됩니다.
- 테두리 점은 한 방향으로 순서대로 찍어 곡선이 스스로 교차하지 않도록 조절하세요. n점원의 둘레·면적은 부드러운 곡선을 이미지 좌표에서 촘촘히 나누어 계산한 근삿값입니다.

### 화면 배율과 작은 화면

절대 좌표에 배치하던 입력칸을 자동 크기 표 레이아웃으로 변경했습니다. 숫자 입력칸 위에 설명을 배치하여 글자와 입력칸이 겹치지 않습니다. 넓은 창에서는 설정과 미리보기가 좌우로, 좁은 창에서는 위아래로 배치됩니다. 내용이 창보다 크면 스크롤로 접근할 수 있습니다. 적용·닫기 버튼은 아래에 있습니다. 창은 현재 모니터의 작업 영역에 맞게 제한됩니다.

### 알아서 배열

- 사진을 선택했다면 선택된 일반 사진·연결 사진·사진 자리표시자만 수집합니다. 텍스트·도형은 그대로 둡니다.
- 아무 사진도 선택하지 않았다면 현재 슬라이드의 일반 사진·연결 사진·사진 자리표시자와 그룹 내부 사진을 수집합니다.
- 현재 위치를 기준으로 위에서 아래, 왼쪽에서 오른쪽 순서를 사용합니다.
- 4~16장은 화면 비율에 관계없이 다음 격자로 앞 행부터 채웁니다: 4장 2+2, 5장 3+2, 6장 3+3, 7장 4+3, 8장 4+4, 9장 3+3+3, 10장 5+5, 11장 4+4+3, 12장 4+4+4, 13장 4+4+4+1, 14장 4+4+4+2, 15장 5+5+5, 16장 4+4+4+4. 17장 이상은 사진과 슬라이드 비율을 비교해 가장 균형 잡힌 열 수를 자동으로 선택합니다.
- 모든 행의 왼쪽 시작점이 같습니다. 마지막 행에 빈자리가 있어도 가운데로 이동하지 않습니다. 배열 전체는 기존처럼 슬라이드 중앙의 여백 영역에 놓입니다.
- 사진 자체의 비율과 회전을 유지합니다. 사진마다 회전 후의 바깥 경계를 계산하여 간격과 여백을 확보합니다.
- 라벨이 붙은 사진은 사진과 라벨의 그룹을 함께 이동하고 같은 비율로 크기를 조절하므로 라벨의 왼쪽 위 정렬이 유지됩니다.
- **배열은 중앙 80% 너비·80% 높이 안에 들어갑니다.** 가로·세로 각각 합계 20%, 각 가장자리 최소 10% 여백입니다. 배열 비율에 따라 한 방향의 여백은 더 커집니다.
- 텍스트·번호 라벨 등은 이동하지 않습니다. PowerPoint 실행 취소(Ctrl+Z)를 지원합니다.

### 빠른 번호 매기기

배치와 도움말 사이의 리본 그룹입니다. 각 형식의 0~10과 다음 값 버튼이 리본에 직접 표시되며 메뉴를 열 필요가 없습니다. 형식별로 3행×4칸에 나누어 놓았습니다. 정사각형과 원은 흰색 채움·검정 숫자·검정 테두리입니다. 알파벳 괄호 형식은 투명한 일반 텍스트 상자입니다.

정사각형·원·`숫자)`의 ‘11+’는 현재 슬라이드에서 같은 형식의 가장 큰 번호 다음 값을 추가하며 최소 11부터 시작합니다. `(알파벳)`은 `(A)`부터 `(K)`까지 직접 표시하고 ‘L+’로 `(L)`부터 이어집니다. 알파벳은 Z 뒤에 AA, AB 순으로 계속됩니다. 번호 정보는 도형 태그에 저장되어 파일을 다시 열어도 이어지고, 형식마다 독립적으로 계산합니다.

버튼을 누를 때마다 현재 그룹 안에 실제 라벨 도형이 있는지 확인하여 라벨이 없는 사진을 찾습니다. 사진이 행과 열로 배열되어 있으면 왼쪽 위부터 오른쪽으로, 행이 완전히 맞지 않아도 가까운 높이의 사진을 한 행으로 보아 같은 순서로 처리합니다. 라벨은 해당 사진의 정확한 왼쪽 위에 놓이고 사진과 하나의 그룹으로 묶입니다. 라벨만 지운 사진은 남아 있는 내부 태그와 관계없이 다시 라벨 대상이 됩니다. 사진이 없거나 모든 사진에 라벨이 붙어 있으면 라벨은 독립 도형으로 만들어져 기존 라벨과 겹치지 않는 빈 위치에 놓입니다.

### 번호 서식 설정과 정사각형 상자 (0.1.16)

1. 빠른 번호 매기기 오른쪽의 **글꼴** 목록에서 글꼴을 바로 선택합니다.
2. **크기 (pt)**에 숫자를 입력하고 Enter를 누릅니다.
3. **글자 색**에서 32가지 색 중 하나를 선택합니다. 원하는 색상 코드가 있으면 옆의 **#** 입력란에 여섯 자리 코드를 입력하고 Enter를 누릅니다.
4. 0~10, L+ 또는 11+ 버튼을 누르면 지정한 서식으로 사진에 라벨을 추가합니다.

별도 대화창이나 저장 버튼 없이 리본에서 설정하며 변경 즉시 자동 저장합니다. 설정은 다섯 가지 번호 형식에 공통으로 적용되며 PowerPoint를 다시 열어도 유지됩니다. 기본값은 Arial 18 pt, 검정이며 크기는 1~400 pt 범위에서 입력합니다. 기존 라벨은 그대로 유지하고 이후 추가하는 라벨부터 새 설정을 사용합니다. 작은 창에서는 PowerPoint가 리본 그룹을 접을 수 있으므로 창을 최대화하면 더 많은 버튼을 한 번에 볼 수 있습니다.

괄호 형식 `(알파벳)`과 `숫자)`도 **투명한 정사각형 텍스트 상자**로 생성합니다. 상자의 한 변과 원의 지름은 글자 크기 1 pt당 0.05 cm로 계산합니다. 따라서 **17 pt는 0.85 cm**, 34 pt는 1.70 cm입니다. 두 자리 이상 번호나 괄호가 상자보다 넓어지는 경우에만 글자가 잘리지 않도록 필요한 만큼 커집니다. 지정한 글자 크기를 자동으로 줄이지 않습니다. 글자는 가로·세로 중앙에 놓습니다. 괄호 형식은 채움과 테두리가 없고, 정사각형·원 형식은 흰 채움과 검정 테두리를 유지합니다.

설정 파일은 `%LOCALAPPDATA%\LabPhotoTools\preferences\number-labels.json`에 저장합니다. 업데이트 시 유지되며 배포 ZIP에는 개인 서식을 포함하지 않습니다.

## 이 PC의 기존 설치 업데이트

1. PowerPoint 파일을 저장하고 모든 PowerPoint 창을 닫습니다.
2. 이 배포 폴더의 **Update.cmd**를 더블클릭합니다.
3. PowerPoint를 다시 엽니다.

이미 준비된 Python 환경과 모델을 재사용합니다. 설치 위치는 `%LOCALAPPDATA%\LabPhotoTools`입니다. 업데이트 스크립트는 실행 중인 PowerPoint를 강제로 닫지 않습니다.

## 새 PC에 설치

Windows 10/11, .NET Framework 4.8 이상, 64비트 Python 3.12가 필요합니다. PowerPoint를 닫고 **Install.cmd**를 실행하면 최초 Python 패키지·모델 준비와 사용자별 등록을 수행합니다. 최초 준비에는 인터넷 연결이 필요합니다. 그 이후 사진 처리는 오프라인입니다. 관리자 권한은 필요하지 않습니다.

## 원본 보존

사진 회전과 배경지우기는 원본 슬라이드를 복제한 다음 복제본에서 처리합니다. 결과 사진은 PNG이며 원래 사진의 애니메이션과 편집 효과가 그대로 유지되지 않을 수 있습니다. 배치·번호 추가는 현재 슬라이드에서 동작하고 실행 취소할 수 있습니다.

## 소스와 빌드

이 버전의 기존 핵심 코드는 사용자가 제공한 0.1.3 DLL에서 ILSpy 7.2.1로 복원했습니다. 원본 C# 프로젝트가 배포 폴더와 설치 폴더에 없어 소스를 복원했으며, UI·리본·자동 배치·번호 기능을 새 소스 파일로 작성했습니다. Python 엔진은 기존 배포본을 유지했습니다. 원래의 COM GUID와 SAFEARRAY 수명 주기 인터페이스를 유지합니다.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Build.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Test.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Test-PowerPoint.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Test-ComBoundary.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Test-Measurement.ps1 -PowerPoint
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Package.ps1
```

빌드는 Windows에 포함된 .NET Framework C# 컴파일러를 사용합니다. 별도 .NET SDK는 필요하지 않습니다. 실제 PowerPoint 통합 테스트의 사진 처리에는 프로젝트의 Python 환경 또는 `config.json`에 지정한 기존 설치 환경이 필요합니다. config.json은 배포하지 않습니다.

## 검증

- 새 C# DLL 빌드 성공.
- 32비트·64비트 네이티브 COM 수명 주기 콜백과 리본 XML 반환 검사 통과.
- 사진 1~1,000장, 가로·세로·정사각형 슬라이드의 자동 배치, 비율·겹침·20% 여백 검사.
- 800×600, 1024×768, 1366×768, 1920×1080, 3840×2160과 100%, 125%, 150%, 200%, 250%, 300%를 조합한 120개 대화상자 레이아웃 검사. 해상도와 배율을 테스트 창의 크기·글꼴·컨트롤 크기로 모사했습니다.
- 실제 설치된 PowerPoint에서 회전 사진과 그룹 사진 자동 배치, 실행 취소, 네 형식 44개 라벨·연속 값·사진 왼쪽 위 정렬·사진과의 그룹화·저장 후 번호 유지, 사진 회전과 오프라인 배경 제거 검사.
- 새 테스트용 프레젠테이션을 사용했으며 사용자의 기존 프레젠테이션은 수정하지 않았습니다.

모든 종류의 모니터·Windows 텍스트 접근성 설정·Office 버전에서 직접 실행한 검증은 아닙니다. 특히 별도 PC의 32비트 Office와 회전된 그룹/중첩 그룹의 좌표 변환은 추가 실기 검증이 필요합니다.
