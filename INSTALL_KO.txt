Lab Photo Tools 0.1.13 설치 및 업데이트

[이미 설치한 PC]
1. PowerPoint 파일을 저장하고 모든 PowerPoint 창을 닫습니다.
2. Update.cmd를 더블클릭합니다.
3. PowerPoint를 다시 실행합니다.
기존 Python 환경과 배경 제거 모델을 재사용합니다.

[처음 설치하는 PC]
Windows 10/11, .NET Framework 4.8 이상, 64비트 Python 3.12가 필요합니다.
PowerPoint를 닫고 Install.cmd를 실행합니다.
최초 패키지와 모델 준비에는 인터넷이 필요합니다.
설치 위치: %LOCALAPPDATA%\LabPhotoTools

[새 기능]
- Lab Photo Tools 안의 치수측정: 사진 한 장 선택 → 자 모양 치수측정 버튼.
  선·평행선·3점원으로 스케일 지정 → 실제 길이/단위 입력 → 스케일 적용.
  선·원·사각형·타원·각도·다각형 등 측정 후 '측정 사진 복사'.
  현재 슬라이드에 측정한 사진과 결과만 추가하고 원래 사진은 유지합니다.
  화면을 크게 채우는 고정 창, 수동 스케일 오른쪽 4:3 확대창.
  WASD/방향키는 이미지 1 px씩, Shift와 함께 누르면 10 px씩 이동합니다.
  사진의 회전과 좌우/상하 반전을 슬라이드에 보이는 그대로 표시합니다.
  스케일과 측정값은 사진에 저장되며, 사진과 함께 이동·크기 조절됩니다.
- 사진 보정 → 사진 회전. 화면 배율에 맞는 레이아웃과 스크롤.
- 배경지우기: 사진 회전 밖의 별도 버튼.
- 자동 배열: 3×3 바둑판 아이콘.
- 간격 조절: 두 상자 사이 양쪽 화살표 아이콘.
- 자동 배열·간격 조절: 사진과 텍스트·도형을 함께 선택해도 사진만 처리.
- 알아서 배열: 사진을 선택하면 그 사진만, 선택이 없으면 슬라이드의 사진 전체를 배치.
  4~16장은 정해진 촘촘한 격자를 쓰고, 더 많은 사진은 균형 잡힌 격자로 자동 배치.
  슬라이드 중앙 80% 영역 사용(각 가장자리 최소 10% 여백).
- 빠른 번호 매기기: 정사각형, 원, (알파벳), 숫자).
  라벨 없는 사진을 왼쪽 위부터 찾아 라벨을 사진 왼쪽 위에 붙이고 사진과 그룹화.
  사진에서 라벨만 지우면 다음 번호 매기기에서 그 사진을 다시 인식.
  사진이 없거나 모두 라벨이 붙으면 독립 라벨을 빈 위치에 추가.
  알아서 배열 때 라벨 사진은 사진·라벨 그룹 전체를 함께 이동.
  알파벳은 (A)~(K)와 L+로, 숫자 형식은 0~10과 11+로 추가.
  17 pt의 기본 상자 한 변·원 지름은 0.85 cm이며 글자 크기에 비례.

사진 회전과 배경지우기는 복제 슬라이드에 적용합니다.
배치와 번호 추가는 Ctrl+Z로 취소할 수 있습니다.

[제거]
PowerPoint를 닫고 Uninstall.cmd를 실행합니다.
