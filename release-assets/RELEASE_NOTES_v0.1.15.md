# Lab Photo Tools 0.1.15 Preview

- 치수측정 도구 버튼 20개를 같은 크기의 4열 × 5행으로 정렬했습니다.
- 선택·이동, 삭제, 실행 취소 등의 편집 버튼도 같은 크기의 4열 × 2행으로 정렬했습니다.
- 오른쪽 패널의 버튼 높이와 여백을 줄였습니다. 수동 스케일 버튼의 크기도 통일했습니다.
- 화면 배율에 맞춰 긴 버튼 이름과 아이콘의 공간을 확보하고, 작은 화면에서는 오른쪽 패널을 스크롤하여 모든 기능에 접근할 수 있습니다.
- 왼쪽 사진의 최대 표시, 오른쪽 4:3 확대창, 기존 측정·배열·번호 기능은 유지합니다.

## 설치

배포 ZIP을 다운로드하고 압축을 푼 뒤 PowerPoint를 닫고 실행하세요.

- 기존 설치 업데이트: `Update.cmd`
- 새 PC 설치: `Install.cmd`

기존 번호 글꼴·색상 설정과 준비된 Python 환경을 보존합니다. Windows 데스크톱 PowerPoint용이며 macOS·웹 PowerPoint는 지원하지 않습니다.
