# Lab Photo Tools 0.1.16 Preview

- 빠른 번호 매기기의 글꼴 설정 오른쪽에 테두리 색·굵기·바탕색 패널을 추가했습니다. 색상표와 직접 입력을 지원하며, 기본값과 없음(투명)을 선택할 수 있습니다. 이후 만드는 라벨에 적용되고 설정은 자동 저장됩니다.
- `알파벳)` 형식을 추가했습니다. A)~K)는 바로 누를 수 있고 L+는 같은 형식의 다음 알파벳을 추가합니다.
- 번호 라벨과 그룹화된 사진도 측정 사진을 복사할 수 있습니다. 새 복사본에는 선택한 사진과 측정 결과만 포함하며, 기존 번호와 다른 도형은 원본 그룹에 남습니다.
- `n점원`은 테두리를 따라 지정한 3~512개 점을 부드러운 닫힌 곡선으로 잇고 면적과 둘레를 표시합니다. 점을 찍고 Enter 또는 우클릭으로 완성하세요.
- 측정값 하나를 선택하고 `점편집`을 누르면 점을 끌어 이동할 수 있습니다. n점원은 주황색 핸들로 곡률을 조절하며, 선택한 점의 `곡률 자동` 복원과 `모서리 점` 전환도 지원합니다. 수정 내용은 실행 취소·다시 실행 및 저장 후 재편집이 가능합니다.
- 측정 도구와 점편집 버튼은 같은 크기의 4열 × 6행으로 표시됩니다. 큰 화면 배율에서 안내 문구가 길어져도 저장 버튼까지 스크롤할 수 있도록 수정했습니다.

## 설치

배포 ZIP을 다운로드하고 압축을 푼 뒤 PowerPoint를 닫고 실행하세요.

- 기존 설치 업데이트: `Update.cmd`
- 새 PC 설치: `Install.cmd`

기존 번호 글꼴·색상 설정과 준비된 Python 환경을 보존합니다. Windows 데스크톱 PowerPoint용입니다.

## n점원 사용

스케일을 먼저 적용하고, 형상의 테두리를 한 방향으로 따라가며 점을 지정하세요. 점편집으로 점과 곡률 핸들을 끌면 면적·둘레가 다시 계산됩니다. 곡선의 면적과 둘레는 곡선을 세분화한 근사값이며, 테두리가 서로 교차하지 않도록 그리세요.
