# Lab Photo Tools 0.1.12 Preview

PowerPoint에 **치수측정** 탭과 자 모양 버튼을 추가했습니다.

## 치수측정 사용법
1. 사진 한 장을 선택하고 **치수측정 → 치수측정**을 누릅니다.
2. 사진의 스케일바를 선·평행선·3점원으로 지정하고 실제 길이와 단위를 입력한 뒤 **스케일 적용**을 누릅니다.
3. 선·원·사각형·타원·각도·다각형 등으로 측정합니다. 휠 확대, 확대창, WASD/방향키 미세 조정, 실행 취소와 CSV 저장을 지원합니다.
4. **복사본에 적용**하면 복제 슬라이드에 편집 가능한 도형과 텍스트를 사진과 묶어 저장합니다.

스케일과 측정 좌표는 사진에 저장되어 다음 작업 때 불러올 수 있습니다. 측정 그룹은 자동 배열·간격 조절·알아서 배열 시 사진과 함께 이동하고 크기가 바뀝니다.

## 설치 / 업데이트
- PowerPoint를 모두 닫고 `LabPhotoTools-0.1.12-preview.zip`을 내려받아 압축을 풉니다.
- 처음 설치: `Install.cmd`
- 기존 설치 업데이트: `Update.cmd`
- Windows 데스크톱 PowerPoint, .NET Framework 4.8, 64비트 Python 3.12가 필요합니다. 처음 설치할 때 패키지와 배경 제거 모델을 준비하므로 인터넷 연결이 필요합니다.
