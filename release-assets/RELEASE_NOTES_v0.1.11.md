# Lab Photo Tools 0.1.11 Preview

Windows 데스크톱 PowerPoint용 COM 추가 기능입니다.

## 주요 변경

- 사진과 텍스트·도형을 함께 선택해도 선택된 사진만 자동 배열·간격 조절
- 사진 수에 맞춘 알아서 배열 규칙과 슬라이드 가장자리 20% 여백
- 빠른 번호 매기기: 정사각형, 원, (알파벳), 숫자)
- 글꼴·크기·색상을 리본에서 설정
- 사진 왼쪽 위에 라벨을 정렬하고 사진과 그룹화
- 라벨을 지운 사진을 다시 찾아 번호 부여
- 라벨이 붙은 사진을 배열할 때 라벨도 함께 이동

## 설치

1. PowerPoint를 모두 닫습니다.
2. `LabPhotoTools-0.1.11-preview.zip`을 내려받아 압축을 풉니다.
3. 처음 설치하는 PC에서는 `Install.cmd`를 실행합니다.
4. 기존 설치를 업데이트할 때는 `Update.cmd`를 실행합니다.
5. PowerPoint를 다시 열고 **Lab Photo Tools** 탭을 확인합니다.

Windows 10/11, .NET Framework 4.8 이상, 64비트 Python 3.12가 필요합니다. 처음 설치할 때 Python 패키지와 배경 제거 모델을 준비하기 위해 인터넷 연결이 필요합니다.
