## 치수측정 사진을 더 크게 표시

- 모든 설정을 오른쪽 패널로 모았습니다. 전체 보기·확대/축소, 수동 스케일과 4:3 확대창, 측정 도구·서식·결과를 한곳에서 사용합니다.
- 사진은 항상 왼쪽에서 창 전체 높이를 사용하며, 원래 비율을 유지하는 최대 크기로 표시합니다.
- 오른쪽 설정만 스크롤됩니다. 작은 화면에서도 사진이 설정 아래로 내려가지 않습니다.
- 높은 화면 배율에서도 입력란과 저장 버튼이 겹치지 않도록 배치를 조정합니다.

4:3 사진과 3650×1860 창을 사용한 비교에서는 사진 표시 면적이 이전 첨부 화면의 약 3배로 증가했습니다. 증가량은 사진 비율과 화면 설정에 따라 달라집니다.

실제 PowerPoint 측정 검사 1,940개, 기존 배열·번호 검사 2,042,571개, 사진·번호 통합 검사 31개와 x86/x64 COM·RibbonX 검사를 통과했습니다.

## 설치

**LabPhotoTools-0.1.14-preview.zip**을 내려받아 압축을 풀고 PowerPoint를 닫은 뒤 실행하세요.

- 기존 설치 PC: **Update.cmd**
- 처음 설치하는 PC: **Install.cmd**

기존 번호 서식과 Python 환경·배경 제거 모델은 유지됩니다.
